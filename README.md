## 📖 Sobre o repositório

Coleção de exemplos e exercícios de **TypeScript**, organizados por tema. Do sistema de tipos básico até generics e utility types avançados.

---

## 🗂️ Estrutura do Repositório

```
.
├── 01-tipos-basicos/          # string, number, boolean, any, arrays, tuples
├── 02-interfaces-e-types/     # interface, type, extends, implements
├── 03-generics/               # Funções e classes genéricas
├── 04-enums-e-utility-types/  # Enum, Partial, Pick, Omit, Record
└── 05-projetos/               # Mini projetos tipados
```
