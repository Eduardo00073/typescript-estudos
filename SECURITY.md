# Politica de Seguranca

Este repositorio (typescript-estudos) e um guia didatico de TypeScript, mantido por Eduardo Junior.

## Reportando um problema

Se encontrar algum problema de seguranca nos exemplos (tipagem insegura, uso de any que oculte falhas, ou dependencias vulneraveis), abra uma issue explicando o contexto.

## Boas praticas recomendadas

- Prefira tipagem estrita ao inves de any sempre que possivel.
- Mantenha as dependencias do projeto atualizadas.
- Nao verslicone arquivos de configuracao com segredos.
